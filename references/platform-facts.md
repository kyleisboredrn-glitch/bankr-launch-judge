# Bankr launch platform facts

Verify against current Bankr docs before treating a team claim as impossible. Docs move.

Typical Doppler launch: fixed supply, ~85% in pool, ~15% vested to the original fee recipient, locked LP, creator earns 95% of the 0.7% pool swap fee.

Public endpoints:
- GET https://api.bankr.bot/token-launches
- GET https://api.bankr.bot/token-launches/<tokenAddress>/fees?days=30
- https://bankr.bot/launches/<tokenAddress>
