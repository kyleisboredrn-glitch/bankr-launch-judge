# Bankr Launch Judge — operator guide

An automated classifier for tokens Bankr deploys on Base and Robinhood Chain.

Labels: `rug` | `vapor` | `slow cook` | `diamond`
Every case stores verified facts, concerns, sustained doubt, and a two-sided thesis.
The ledger is append-only so later reviews can see pattern and anomaly against prior cases.

This is classification, not financial advice.

## Install on Bankr

```
install the bankr-launch-judge skill from https://github.com/kyleisboredrn-glitch/bankr-launch-judge
```

Then schedule the prompt in `references/automation-prompt.md` every 1–2 hours.
Keep the live ledger on the Bankr filesystem at `/cases/bankr-launch-judge/ledger.json`.
